# Contributing

Thank you for helping. Before your first pull request:

1. **Contributor License Agreement.** A bot will ask you to sign the CLA on your first PR. It grants the project
   owner a license to your contribution so the project can keep evolving (including future licensing decisions);
   you keep your copyright.
2. **Read [AGENTS.md](AGENTS.md).** The same rules apply to humans and AI agents: blocks never import each other,
   schema only through migrations, RLS everywhere, no tracking, UI text only in `messages/es.json`.
3. **One change per PR**, on a branch, with a short description in plain language. CI must be green.
4. **Language:** code, comments and commits in English; UI text in Spanish.
5. **Never** commit secrets, real personal data, or data about real associations in seeds or tests.

Good first issues are labelled `good first issue`.
