| evento | evento | `event` |
| co-organizzatore | coorganizador | `event_organizers.role = 'co'` |
| filo | hilo | `thread` |
| storia del filo | historia | `story_proposer`, `story_receiver` |
| quartiere | barrio | `neighborhood` |
| spazio disponibile | espacio disponible | `space` |
| invito | invitación | `invite` |
| home privata | panel | `/panel` |
| numero di registro | número de inscripción | `registry_number` |
| stato di luce | estado de luz | `light state`: `pulse`, `lit`, `faint` |
